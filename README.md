# harrylabs-games.github.io

Static site for **HarryLabs Games** and **Tubiluz** (GitHub Pages, user site).

> ⚠️ The privacy policy and terms of use are **templates, not legal advice**. Have them reviewed by a lawyer
> (ideally one familiar with Colombian Ley 1581 de 2012, GDPR and LGPD) before relying on them.
> Each legal page shows a small "template notice" box (`<div class="template-note">`); delete it after review.

## Publish
1. Create the GitHub account/organization **harrylabs-games** (already planned) and a **public** repo named exactly
   `harrylabs-games.github.io`.
2. Copy the *contents* of this folder to the repo root (keep `.nojekyll`, `app-ads.txt` at the root) and push to `main`.
3. Repo → Settings → Pages → Source: *Deploy from a branch*, branch `main`, folder `/ (root)`. Enable *Enforce HTTPS*.
4. Check: `https://harrylabs-games.github.io/`, `/tubiluz/`, `/tubiluz/privacy/`, `/tubiluz/terms/` and `/app-ads.txt`.
