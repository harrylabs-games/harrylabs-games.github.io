# harrylabs-games.github.io

Static site for **HarryLabs Games**, **Tubiluz** and **Gumbloc** (GitHub Pages, user site).

Since v0.5.0 (Nov 11, 2026) this is a **legal-only** site: the marketing landing (game card, feature
graphic, screenshots, feature lists, beta-tester presentation) was removed because testers now come
through the paid Testers Community service. What remains, at the same URLs:

| Path | Why it stays |
|---|---|
| `/` | Simple page with the developer name, contact email and links to the legal pages (Play "Website" field) |
| `/tubiluz/` | Same links (stable URL; older links point here) |
| `/tubiluz/privacy/` (+ `es.html`, `pt-br.html`, `de.html`) | Privacy policy, required by Play Console and linked from the app |
| `/tubiluz/terms/` (+ `es.html`, `pt-br.html`, `de.html`) | Terms of use |
| `/gumbloc/`, `/gumbloc/privacy/`, `/gumbloc/terms/` (same 4 languages) | Gumbloc legal pages (added Nov 13, 2026; adds the Google Play in-app purchase «Remove ads») |
| `/app-ads.txt` | Required by AdMob at the domain root |
| `/404.html`, `/robots.txt` | Housekeeping |

When publishing, replace the repository contents with this folder so the old landing files
(`tubiluz/img/`, `assets/shots/`, `assets/feature-graphic.png`) are deleted too.

> ⚠️ The privacy policy and terms of use are **templates, not legal advice**. Have them reviewed by a lawyer
> (ideally one familiar with Colombian Ley 1581 de 2012, GDPR and LGPD) before relying on them.
> Each legal page shows a small "template notice" box (`<div class="template-note">`); delete it after review.

## Publish
1. Create the GitHub account/organization **harrylabs-games** (already planned) and a **public** repo named exactly
   `harrylabs-games.github.io`.
2. Copy the *contents* of this folder to the repo root (keep `.nojekyll`, `app-ads.txt` at the root) and push to `main`.
3. Repo → Settings → Pages → Source: *Deploy from a branch*, branch `main`, folder `/ (root)`. Enable *Enforce HTTPS*.
4. Check: `https://harrylabs-games.github.io/`, `/tubiluz/`, `/tubiluz/privacy/`, `/tubiluz/terms/` and `/app-ads.txt`.
